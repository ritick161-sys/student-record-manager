# Student Record Management System (CLI)

A menu-driven Command-Line Interface (CLI) application built in Python for managing student academic records with persistent JSON storage and CSV export.

## Features
- **Full CRUD Operations:** Add, view (ranked by average), search (by ID or name), update details/marks, and delete student records.
- **Persistent Storage:** Automatically saves changes to `students.json` and supports exporting reports to `students.csv`.
- **Clean Pythonic Design:** Uses `*args` and `**kwargs` for flexible calculations/updates, `lambda` sorting, list comprehensions, and `try/except/finally` validation.
